Project: SbuRec
Purpose: Frontend for exploring Classie evaluation CSV data (compute and visualize course easiness, instructor stats, and comments). The app currently boots by loading the packaged CSV from `public/data` and parsing it in-browser.

Stack
- React + TypeScript (Vite)
- Tailwind CSS
- Zustand for client state
- PapaParse for CSV parsing

Runtime / Config
- Dev: `npm run dev` in `frontend`
- Static asset: `public/data/classie_evaluations_with_sbc.csv` is served as `/data/classie_evaluations_with_sbc.csv`
 - Static assets: the large CSV has been sanitized and split into four parts and is served from the frontend `public` folder as:
	 - `/classie_evaluations_with_sbc_part1.csv`
	 - `/classie_evaluations_with_sbc_part2.csv`
	 - `/classie_evaluations_with_sbc_part3.csv`
	 - `/classie_evaluations_with_sbc_part4.csv`

Dev notes / How to build locally:
1. From `frontend`: `npm ci` to install dependencies. If `npm ci` fails with EPERM unlink errors on `esbuild.exe` on Windows, try:
	- Close any running dev servers/editors that may lock files.
	- Delete `node_modules\@esbuild` directory manually.
	- Re-run PowerShell as Administrator and run `npm ci` again.
2. Run `npm run build` to run TypeScript and Vite build. If `tsc` is not recognized, ensure `node_modules/.bin` is available (install dev dependencies) or install TypeScript globally.
